# DyHealthNet Frontend with Vue.js

Frontend is developed with Vue 3 in Vite.

## Project Setup
1. Install Node.js: https://nodejs.org/en
3. Install Vue
4. Install Vite
5. Install Vuetify
6. Install Router

  ```sh
  npm install vite
  npm install vuetify
  npm install router
  npm install vis-network
  npm install axios
  ```

### Compile and Hot-Reload for Development

```sh
npm install 
npm run dev
```
